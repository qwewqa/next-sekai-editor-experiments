Stored File Handle Probe

Dev server only. Marker: nse-handle-probe.

  1. Pick a File, then Store. The log should say the handle was stored.
  2. Reload this page (F5). If the tab closes or crashes, reading a stored handle is not safe in this browser.
  3. Read Back. The log shows the file name and size, the permission state, and asks before writing a line to the file.

Also try: close the whole browser, open it again, open this page, and Read Back.
