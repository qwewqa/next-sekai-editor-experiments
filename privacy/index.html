Who Runs This

%PRODUCT_NAME% is an editor for the Next SEKAI engine in Sonolus. It is an open-source project by qwewqa.

Contact: nse@qwewqa.dev. Report bugs on the GitHub issues page. Send privacy questions and requests by email.

The Short Version

The web editor does not collect anything about you. There are no accounts, no analytics, no cookies and no crash reports, and we run no server that receives your data: the site is static files on GitHub Pages.

The Web Editor

  • Your editing sessions and their history, settings and stored assets stay in this browser’s storage. Files go only where you save them.
  • Audio you choose (BGM, preview audio) and covers are stored with the sessions that use them. A BGM you replace is kept only as a cache, which is removed first when space runs low.

Requests It Makes

  • Loading the site from nse.qwewqa.dev, hosted by GitHub Pages. GitHub may log requests, including your IP address. See GitHub’s privacy statement.
  • Sonolus servers you enter in Preview Assets: requests go to that server only. Each carries your IP address, your browser’s user agent and the editor’s language (in the localization parameter). No cookies are sent, and thumbnails are loaded without a referrer.
  • Automatic re-download: if you chose an item from a server and the browser has since cleared it, the editor downloads it again from that server when it starts, with the same contents as above.

Content from Servers and Files

Items you load from a server or a file are stored on your device only. The content stays under its server operator’s or author’s terms.

What We Keep, and Deleting Your Data

  • We keep nothing. GitHub’s request logs are kept under GitHub’s policy. Questions go to nse@qwewqa.dev.
  • Files you send us. If you send us a file to fix a problem (a project, or a raw data export from Settings › Local Data › Recovery), we use it only for that and delete it when the problem is fixed. Send it by email, not in a public issue: it holds your charts and audio.
  • On the web: Settings › Local Data › Delete Sessions…, Preview Assets › Stored for stored assets, or clearing the site’s data in your browser.
  • Your choices: enter only the servers you want contacted.

Changes

The date at the top of this page shows its last change, and the changelog lists each release. A change in what is sent, for example adding crash reporting, would be announced in the release notes.
