Privacy

Last updated: October 26, 2026

Your Data and Choices

Your charts, editing history and stored assets stay on your device. Files go only where you save them. The web editor works without accounts or cookies and does not send crash reports.

The editor sends usage statistics to a server we run to help improve the editor. No statistics are sent before your first interaction, such as clicking or pressing a key. Turn off Settings › About › Send Usage Statistics to stop sending immediately.

Statistics are on by default unless your browser sends Do Not Track or Global Privacy Control. You can override this with the setting. Your choice applies to this browser only. Clearing the site’s data resets it, so statistics are on again unless your browser sends either signal.

Who Runs This

%PRODUCT_NAME% is an editor for the Next SEKAI engine in Sonolus. It is an open-source project by qwewqa. qwewqa runs this site and is responsible for the use of personal data described here.

Send privacy questions and requests to nse@qwewqa.dev. Report bugs on the GitHub issues page.

Data in Your Browser

Your sessions, their history, settings, audio, covers and preview assets are kept in this browser’s storage. When space runs low, the editor may delete audio and covers used only by earlier Timeline steps. Your browser may also clear the site’s storage. Settings › Local Data shows the storage status.

To delete sessions, use Settings › Local Data › Delete Sessions… or History › Recent Sessions. Discard recovered work in Settings › Local Data, and remove stored assets in Preview Assets › Stored. Deleted sessions may remain in browser storage until automatic cleanup runs. Clearing the site’s data in your browser deletes all data stored there.

Usage Statistics

We use these statistics to understand how the editor is used and improve its reliability and performance. Our legal basis is our legitimate interest in improving the editor.

  • Tools and Settings. Which tools and commands you use, how often you use them, and settings such as theme, language and preview options.
  • Files and Charts. File types and sizes, chart sizes, music lengths and whether actions such as opening or saving a file succeed.
  • Performance. How long startup and file actions take, how often the editor responds slowly, time spent using it and counts of notices and errors.
  • Browser and Device. The editor version, browser, operating system, language, screen and window sizes, processor cores and memory.
  • Storage. Whether browser storage is available, how much space it has and whether automatic cleanup frees space.
  • Referring Sites. The site you followed a link from, without the page path, query or fragment.

Statistics do not include your charts or their content, file names, level titles, other text you type or identifiers stored in your browser.

Chart sizes, music lengths and file sizes are sent as ranges, except that chart object counts below 10 are sent exactly. Together these figures can sometimes match a published chart.

See the complete list of what is sent for each field, its meaning and how measurements are recorded.

If your browser is too old to open the editor, the page that tells you so reports the browser family, such as Firefox or Safari, and that it is unsupported. It follows the same statistics setting and browser signals, and sends only after your first interaction.

Counting Visits

The statistics server receives your IP address and user agent, the information your browser sends about itself. It uses them to count visits and find your country, browser, operating system and device type. It may also find your region and city. Of these details, only country, browser, operating system and device type are stored in the statistics.

The server also keeps a daily visitor code made from your IP address and user agent. This groups a browser’s activity within a day, and the code changes each day. People using the same browser type on the same connection can share a code. The statistics server sets no cookies and stores nothing in your browser.

Where Data Is Processed

GitHub Pages hosts this site. GitHub may log requests, including your IP address, and keeps those logs under its own privacy statement.

We process and store usage statistics on Amazon Web Services (AWS) servers in the United States. AWS provides hosting and backups and is the only provider with whom we share these statistics. We keep them separate from data from other sites. Only the maintainer has access to the statistics dashboard.

For transfers subject to EU data protection rules, we rely on the European Commission’s Standard Contractual Clauses, which are part of AWS’s terms.

How Long We Keep Data

We keep individual usage statistics for 13 months.

We keep monthly and weekly totals indefinitely. These contain combined figures with no visitor codes. Small groups are combined into larger groups or omitted.

Backups on AWS are deleted after about five weeks.

Server error logs may contain your IP address after an unexpected failure. We delete these logs after two weeks.

Email and Files You Send Us

When you contact us, we use your email address and message to answer you and keep the conversation in our mailbox. If you send a file to help fix a problem, we use it only for that and delete it when the problem is fixed.

A project file or a file from Settings › Local Data › Export Raw Data can contain your charts and audio. Send it by email to nse@qwewqa.dev and keep it out of public issues.

Your Rights

Depending on the law that applies, you may have rights to access, correct or delete your personal data, restrict its use, or object to its use. Send requests to the email address above. You may also complain to your local data protection authority.

Usage statistics use a daily visitor code in place of a name or account. We may therefore be unable to identify records that relate to you.
