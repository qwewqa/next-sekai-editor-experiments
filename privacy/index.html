Privacy Notice

Last updated: October 27, 2026

Summary

Your charts, editing history, settings and preview assets are stored in your browser. Clearing this site’s data in your browser deletes them. The editor does not require an account or use cookies.

The editor sends us usage statistics, such as which tools you use and how long actions take. They are on by default unless your browser sends a Do Not Track or Global Privacy Control signal. You can turn them on or off for this browser in Settings › About › Send Usage Statistics. If you turn them on or off yourself, the editor follows your choice instead of these browser signals.

The editor asks you to agree to the Terms of Service in a window before you first use it, and again after some changes to those terms or to this notice. The window also shows this setting and links to this notice. Usage statistics from the editor are sent only after you agree. If your browser cannot run the editor, the page that says so may send a report about the browser before you agree.

Data Controller

%PRODUCT_NAME% is an open-source project run by qwewqa, the data controller for the personal data described in this notice.

Send privacy questions and requests to nse@qwewqa.dev.

Usage Statistics

We collect usage statistics to understand how the editor is used and to improve it. They include:

  • Tools and commands you use, some editor settings and time spent in the editor.
  • How long actions take, other performance measurements and the number of errors.
  • File types and sizes, chart sizes (such as the number of notes), and the length of the music.
  • Results of attempts to open, save or export files.
  • Browser and device details, language settings, screen size, your country and the site that referred you.
  • Whether browser storage is available, how much is used and its limits.

The statistics do not include chart content, file names, level info or other text you type. For the full list, see What Usage Statistics Contain.

Counting Visits

We count visits without using cookies or storing a visitor identifier on your device. Our server creates a visitor identifier from your IP address and browser details using a one-way hash and a secret key. It changes every day, so visits on different days have different identifiers. We use it only to count visits, never to identify you.

We store the identifier with individual usage records. We also use your IP address to estimate your country. The statistics do not contain your IP address, but error logs on the statistics server may contain it.

Email and Support

When you email us, we use your email address, message and any attachments to respond.

If you send a file to help us investigate a problem, we use it only for that and delete it once the problem is fixed.

Legal Basis

  • Legitimate interest: improving the editor and answering your messages.
  • Legal obligation: answering requests to exercise your data protection rights.

Hosting and Sharing

This site is hosted on GitHub Pages. GitHub logs visitors’ IP addresses for security purposes, as described in GitHub’s privacy statement.

We use Amazon Web Services (AWS) in the United States to host the statistics server and store its backups. We do not share usage statistics with anyone else.

Our email provider stores the messages and attachments you send us.

How Long We Keep Data

  • Individual usage records, including visitor identifiers: up to 13 months.
  • Backups of the statistics: up to six weeks after each backup is made.
  • Error logs on the statistics server: up to two weeks.
  • Email conversations: up to one year after your last message.

Aggregated statistics contain no visitor identifiers and are kept indefinitely.

Your Rights

You have the right to access, correct or delete your personal data, to restrict how we use it and, in some cases, to receive a copy in a reusable format. You also have the right to complain to your local data protection authority.

You have the right to object at any time to our use of your personal data for usage statistics or support. You can also turn off usage statistics in Settings › About › Send Usage Statistics.

To exercise any of these rights, email nse@qwewqa.dev.
