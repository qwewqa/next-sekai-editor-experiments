Who Runs This

%PRODUCT_NAME% is an editor for the Next SEKAI engine in Sonolus. It is an open-source project by qwewqa.

Contact: nse@qwewqa.dev. Report bugs on the GitHub issues page. Send privacy questions and requests by email.

The Short Version

The web editor has no accounts, cookies or crash reports. It sends usage statistics to our own server, such as which tools you use and how long actions take. It never sends your charts or file names. Turn them off in Settings › About › Send Usage Statistics. The site itself is static files on GitHub Pages.

The Web Editor

  • Your editing sessions, their history, your settings and your stored assets stay in this browser’s storage. Files go only where you save them.
  • BGM, preview audio and covers are stored with the sessions that use them. When space runs low, audio and covers may be deleted if only earlier Timeline steps use them. No other data is deleted automatically. Your browser may also clear this site’s storage. Settings › Local Data says when.

Requests It Makes

  • Loading the site from nse.qwewqa.dev, hosted by GitHub Pages. GitHub may log requests, including your IP address. See GitHub’s privacy statement.
  • Usage statistics to stats.nse-services.qwewqa.dev, unless you turn them off. See Usage Statistics.

Usage Statistics

The editor sends these to stats.nse-services.qwewqa.dev, a server we run on Amazon Web Services in the United States:

  • how often each tool, command and kind of edit is used, and how it was started, such as from a key, the toolbar or a menu;
  • the main settings, such as the theme, the language and whether the minimap is shown;
  • the kind and approximate size of files you open, save and export, what a save included, and whether that worked;
  • the approximate length of music files;
  • the approximate size of the chart and of its Timeline, such as “1,000 to 2,000 notes”, and approximately how many sessions Recent Sessions lists;
  • how a visit started, for example whether earlier work was recovered, and how many notices and errors appeared, without their messages;
  • how long startup takes, how long it takes to open, save, export and check files and to load music, and how long the chart takes to show at a Timeline step;
  • whether Check File and History found problems, how often the editor is slow to respond, and how long playback ran and the editor was visible, in seconds;
  • the editor’s version, whether it was updated since your last visit, and whether this browser has used it before;
  • your operating system, browser and its language, your screen size and pixel density, an approximate window size, whether the screen is a touch screen, the number of processor cores as a range, whether the preview could use graphics and draw in parallel, and whether the editor is installed;
  • whether this browser’s storage is available, whether this looks like a private window, and approximately how full it is;
  • the site you came from, if you followed a link from another site, without the rest of its address.

Each is sent with the time it happened.

It never sends your charts or their content, file names, level titles or other text you type, or any identifier stored in your browser. Counts, such as how often a tool is used, and those two times in seconds are sent as numbers up to 9999. The screen size is sent as it is. Other numbers, such as sizes and how long actions take, are sent as ranges.

The server receives your IP address and browser’s user agent with each request. It uses them to count visits and to find your country, and does not store them. It also finds your region and city, and deletes them within a day. To count visits it keeps a code made from them that changes every day. It sets no cookies and stores nothing in your browser.

We keep the statistics with no time limit for now. The release notes and this page will announce any limit we set. Only the maintainer can see them.

Nothing is sent from a visit until you use the editor, for example by clicking or pressing a key.

Turning them off. Turn off Settings › About › Send Usage Statistics. Nothing more is sent from that moment. If your browser sends Do Not Track or Global Privacy Control, the editor sends nothing unless you turn the setting on.

Content from Files

Skins and other preview assets you load from a file are stored in this browser only. They stay under their authors’ terms.

What We Keep, and Deleting Your Data

  • Usage statistics. We keep the usage statistics described above with no time limit for now. They contain no name, account or identifier, so there is no way to find or delete one person’s statistics. To stop any more being sent, turn off Settings › About › Send Usage Statistics. Questions go to nse@qwewqa.dev.
  • GitHub’s logs. GitHub keeps its request logs under its own policy.
  • Files you send us. If you send us a file to help fix a problem, we use it only for that and delete it when the problem is fixed. This can be a project file or the file from Export Raw Data in Settings › Local Data › Recovery. Send it by email, not in a public issue. It contains your charts and audio.
  • Data in your browser. Delete sessions with Settings › Local Data › Delete Sessions… or in History › Recent Sessions. Discard recovered work under Settings › Local Data › Recovery. Remove stored assets in Preview Assets › Stored. Clearing the site’s data in your browser deletes all of it.

Changes

The date at the top of this page shows when it last changed, and the changelog lists each release. The release notes would announce any change in what is sent, for example adding crash reporting.
