# Changelog

## Unreleased

- Added Show Combo to Preview Settings and Settings › Preview.
- Added Test Aspect Ratio to Preview Settings, Settings › Preview and Export Video.
- Preview Settings now opens in the Preview panel when most of it fits. You can scroll to see the rest.
- In the Properties panel, Settings and dialogs, a value now goes below its label when a word in the label does not fit beside the value. In Brush Properties, it also does so when the label would wrap onto more than two lines.
- When objects of several kinds are selected, the Properties panel now shows General first. Beat now also appears for notes and events selected together with BPM changes or time scales. Notes and stage transform events now have separate Elevation fields, both when selected together and in Brush Properties.
- The BGM no longer plays briefly when you move the playback cursor with the preview, Jump to Start, Jump to End, Stop or the Elevation Editor.
- With a lane limit set, moving, pasting or resizing several objects now keeps them together and stops when the first reaches the limit.
- Fixed missing bends in elevated connectors with Back or Elastic easing.
- Improved preview performance for curved connectors between elevated notes.
- Antialiasing is now off by default in the preview. To turn it on, use Preview Settings or Settings › Preview.
- With Antialiasing on, small and distant notes and effects in the preview shimmer less.
- (Web) In Chrome on Android, the Light theme no longer turns partly dark when the phone is in dark mode.
- (Web) The editor now requires Chrome or Edge 111 or later, Firefox 128 or later, or Safari 17 or later. On iPhone and iPad, it requires iOS 17 or later.
- (Web) By default, the editor now sends usage statistics unless Do Not Track or Global Privacy Control is enabled in your browser. To stop sending them, turn off Settings › About › Send Usage Statistics. The privacy page lists what is sent and how long it is kept.
- (Web) Before you first use the editor, you agree to the Terms of Service in a welcome window that also has the Language, Theme and Send Usage Statistics settings. The window appears again after some changes to the Terms of Service or the Privacy Notice. Usage statistics from the editor are sent only after you agree. The unsupported-browser page may send a browser report before you agree.
- (Web) Added the Terms of Service, linked from Settings › About, Help and the privacy page.
- Some settings now have an info button that shows what the setting does.
- Some chart properties now have an info button that shows what the property does. To hide these buttons, turn off Settings › Editor › Show Property Descriptions.
- Save (P or Ctrl/Cmd+S) now saves a project file (.nxsp) instead of level data. The file contains the chart and Level Info, and can include the history and BGM. Open (O) opens project files.
- Export Level Data (Shift+P) exports level data for Sonolus.
- (Web) Added Settings › Local Data › Write to Chosen Files in browsers that support it. On Auto, saves and exports are written to the files you choose or downloaded, depending on the browser. Disabled always downloads them.
- (Web) When saves and exports are written to the files you choose, saving again updates the project file and exporting level data again updates the exported file.
- (Web) When a save or export cannot be written to the file you chose, an error message now says so. It also says if the file was left empty.
- (Web) Some save and export errors now offer Always Download. It sets Write to Chosen Files to Disabled and retries the save or export.
- (Web) The editor stores your work in your browser as sessions and resumes your last session when you return. On the first launch after this update, it opens your old auto save. Save a project file to keep your work.
- Reset is now New (N). New shows a confirmation when the chart has unsaved changes. The previous session stays in Recent Sessions. The notice shown after New has a Reopen button to return to it.
- Added History (Shift+H), with Timeline and Recent Sessions tabs. Timeline lists each change. You can view the chart at any Timeline step and choose Restore to return to that version.
- Recent Sessions lists earlier sessions. Select one to view or restore it, or use its menu to save it as a project file or delete it. You can undo the deletion.
- Recent Sessions has a Delete Sessions button (trash can and clock icon) for deleting several sessions at once.
- Added Find Edits Here to the chart’s context menu. It filters the Timeline to steps that changed the selected beats or the beats in view.
- Undo now supports up to 1,000 steps, even after you reload the page. Earlier Timeline steps are available in History.
- (Web) When browser storage runs low, the editor deletes audio and cover images used only by earlier Timeline steps. Once storage is full, new changes are not stored until you free up space, for example with Delete Sessions in Settings › Local Data.
- Settings › Local Data replaces the Auto Save settings. Its Export Raw Data button exports everything the editor has stored in your browser as a ZIP file, for reporting a problem.
- Reset Settings and Reset Shortcuts now show a confirmation before they reset.
- (Web) Except on iPhone and iPad, a confirmation appears when you close a tab with unsaved changes. This also applies after an export. To turn this off, use Settings › Local Data › Ask Before Closing with Unsaved Changes.
- Level Properties is now Level Info, with title, artists, author, rating, tags, description, cover and preview audio. These are saved in the project file. The text fields in Level Info and the names of groups, stages and folders now have a maximum length.
- The BGM dialog now has a Download BGM button. When the BGM is not loaded, a notice offers Choose Audio to load an audio file.
- Level Info now has a Check button for the project file and the history stored in your browser. It uses the file to repair damaged history where possible and reports any remaining damage. In Settings › Toolbar and Settings › Keyboard Shortcuts, the command is named Check File and History.
- Added Preview Assets for choosing the skin, particle effects, background and sound effects. It is on the toolbar and in the Preview panel’s menu, Preview Settings and Settings › Preview. The choices include the editor’s Built-in assets.
- Open (O) now opens Sonolus packages (.scp). A package with one level and nothing else opens that level. Otherwise, a list shows each level with Open, and each skin, particle effect, background and set of sound effects with Import. Import adds the item to Preview Assets and uses it.
- (Web) The editor now also includes the Next SEKAI 02 skin and sound effects.
- (Web) Replaced the preview’s Default background with a new image.
- Added a minimap beside the chart. It shows the whole chart and the selection, and marks the changes made at the Timeline step you are viewing. Click or drag in it to scroll, or drag its edge next to the chart to resize it. It is shown by default in wide windows. To show or hide it, use the Minimap tool or Settings › Editor › Show Minimap. To choose its side, use Settings › Editor › Minimap Side.
- Added Statistics to the toolbar. It shows the combo, the count of each note type, Notes per Second and the times of the first and last notes. You can zoom and pan the Notes per Second graph, or show it as a distribution. Copy Text copies the statistics, and Share Image makes an image of them to share, copy or download. If you have customized the toolbar, add Statistics in Settings › Toolbar.
- (Web) Added Export Video to the toolbar. It makes a video of the preview for the whole chart or part of it, with optional BGM and sound effects. If you have customized the toolbar, add Export Video in Settings › Toolbar. Usage statistics include each export’s settings, outcome and time taken. They also record whether you used Play or opened Advanced in Export Video.
- When Preview, Groups and Stages are all shown in the left panels or all in the right panels, and those panels are wide, Groups and Stages are now shown side by side below Preview. To widen the panels, drag the edge between the panels and the chart. To use this in narrower panels or turn it off, use Settings › Panels › Groups and Stages Side by Side.
- Stage style events now support Lane Color. Color transitions use the event’s easing. The judgment line keeps its opacity during color transitions.
- Stage transform events now support Rotation Center (Stage Center, Mask Center, Screen Center or Vanishing Point), Center X Offset and Center Y Offset. New stage transform events default to Stage Center. While Highlight Selection is on, the preview shows an X at the rotation center of each stage with a selected stage transform event.
- Level data now opens when it leaves out a stage transform event’s rotation, translation or anchor, a camera event’s lane or size, or an event’s easing. It also opens with any camera size of 0 or more. The editor reads missing values as Sonolus does.
- You can now middle-click in the chart or the Elevation Editor and move the mouse to scroll. Click again to stop.
- With Settings › Toolbar › Quick Switch enabled, you can now press and hold a tool button, then drag along its toolbar row to select another tool.
- Moving or pasting a BPM change onto a beat that has more than one BPM change now replaces all of them. Previously, only one of them was replaced.
- Scale Beats, Scale Width and Scale Elevations no longer delete or reorder unselected objects on the same beat as a selected object. When Scale Beats or Flip Vertically moves an event onto a beat that has other events, those events are now kept, as when dragging.
- Flip Horizontally now flips the Editor Lane of selected time scales, or of selected stage style events, when the only other selected objects are BPM changes. Flip Vertically no longer deletes selected BPM changes or time scales that are at nearly equal beats.
- When several notes of one slide are selected, a note added with the Slide tool now copies the properties set to Copy from the note it follows in that slide, or from the slide’s first note when added before it.
- Clipboard History now counts copied BPM changes.
- (Web) Ctrl/Cmd+R now reloads the page and Ctrl/Cmd+F opens the browser’s find bar. Previously, these shortcuts ran the commands assigned to R and F. You can assign either shortcut to a command in Settings › Keyboard Shortcuts.
- Added an About section in Settings with the editor version and a Copy Diagnostic Info button.
- The preview now renders in parallel with the rest of the editor. This makes chart rendering smoother during playback and editing, especially with dense charts. If the preview looks wrong or does not appear, turn off Settings › Preview › Parallel Rendering.
- When nothing on the screen changes, the editor no longer redraws, so it uses less power.
- Scrolling a zoomed-out chart and playback on phones are smoother.
- Dragging to the top or bottom edge of the chart now scrolls at an even speed.
- Settings opens faster.
- Large level files open faster, especially on phones.
- In the preview, hit effects now stay on their notes when the camera moves, and notes attached across stages line up as they do in Sonolus.
- On iPhone and iPad, audio now plays in silent mode.
- On iPhone and iPad, Play now works after the audio is interrupted, for example by a call or another app.
- Suggested file names containing dots, such as “feat. Miku”, are no longer cut off at the first dot.
- (Web) On Android, dragging down in a dialog no longer reloads the page.
- (Web) If a session did not finish opening last time, a prompt shows Try Again and Start Blank. The session stays in Recent Sessions.
- Audio files can be up to 90 minutes long.
- A confirmation appears before opening a project file larger than 256 MB. Level files larger than 256 MB are not opened.
- (Web) Added safe mode. If the editor does not start, add ?safe to its address.
- Help now has an entry for each tool, in sections with an index as in Settings. It opens at the entry for the tool you are using, at History while you view a Timeline step or a session, or at the Elevation Editor when it fills the chart. Each entry starts by explaining what its tool does.
- Added Settings › Touch › Quick Scroll Zone Side.
- Added Settings › Touch › Show Resize Handles.
